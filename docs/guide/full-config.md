# Full configuration file

This is the complete reference configuration. It is exactly the file that `npx @abap/ui5-blueprint-audit --init` writes. It lists all 33 rules with their default severity and all parameters, set to their default values. Copy it and delete the lines you do not need: the config only overrides what it states.
