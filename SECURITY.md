# Security Policy

## Supported Versions

Only the latest released version is supported with security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please report security issues privately via
[GitHub Security Advisories](https://github.com/tobiashofmann/UI5-BlueprintAudit/security/advisories/new),
not as a public issue.

Reports are reviewed, but this is best effort — there's no guaranteed response time. If a
report is confirmed, a fix will be released at some point, either as its own patch or as
part of a regular update. Where possible, the reporter will be credited in the changelog,
but that's not guaranteed either.
