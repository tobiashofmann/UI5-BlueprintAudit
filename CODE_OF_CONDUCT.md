# Code of Conduct

Keep it professional. Criticize code and ideas, not people.

- Focus on the technical content — not on anyone's personal beliefs, identity, or background.
- Bluntness about bad code or bad ideas is fine. Insults aimed at a person are not.
- No harassment, no personal attacks.
- If you wouldn't say it in a code review with your boss watching, don't say it here.

Violations get a warning; repeated or serious ones get you blocked from the repo. To report
an issue, contact the maintainer directly via [itsfullofstars.de](https://www.itsfullofstars.de).
